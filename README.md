# Архівна стаття для портфоліо

Готова статична сторінка, відновлена зі збереженої копії публікації Zagrava Studios.

## Як переглянути

Відкрийте `index.html` у браузері. Підключення до інтернету не потрібне: текст, стилі та всі зображення зберігаються локально.

## Як опублікувати

Завантажте `index.html` разом із папкою `assets` на будь-який сервіс статичного хостингу. Важливо зберегти назву папки та її розташування поруч із `index.html`.

Для GitHub Pages додайте ці файли в корінь репозиторію та ввімкніть публікацію Pages із потрібної гілки. Для сервісів із drag-and-drop завантажте всю папку `portfolio-article-site`.

## Що можна змінити

У `index.html` можна відредагувати:

- назву студії та інформацію про автора;
- архівну примітку;
- кольори у змінних на початку секції `<style>`;
- метаопис сторінки для пошукових систем і прев’ю посилання.

Перед публікацією переконайтеся, що маєте право розміщувати текст і зображення у відкритому доступі.
